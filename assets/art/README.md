# Final Art Assets

This directory is the stable import target for Veilfall's final visual assets.

Do not put gameplay logic here. Scenes/scripts should reference assets in these folders so artwork can be upgraded independently.

Planned folders are represented by marker files until actual raster assets are imported:
- characters/player
- characters/companions
- characters/enemies
- world/greyhaven
- world/shared
- ui
- fx

See `/ART_DIRECTION.md` for the visual and technical specification.
